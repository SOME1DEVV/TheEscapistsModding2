# Отчёт: проверка присланных `TheEscapists_*.exe.txt`

Здесь лежат три файла из заливки `e4b226b` («Add files via upload») — те самые
изменённые exe, которые «ломаются и не запускаются». Проверка выполнена
разбором чанков Clickteam Fusion + разбором событий фрейма `npc_rename`
(инструменты: `tools/te1_events.py`, движок `launcher_src/te1_engine.py`,
`--check-exe`).

## Что именно совпало, а что отличается

* **События мода — байт-в-байт**: sha1 восстановленного списка событий фрейма
  `npc_rename` = `232e78481d3366ea9cf97a5f29a4deaa3bd216c2` и в присланных
  файлах, и в эталонных. Пять действий `GuardName_1..5` = `Cell Key`,
  `Utility Key`, `Entrance Key`, `Staff Key`, `Work Key` на месте, порядок
  групп и смещения целы.
* **Все остальные 12 фреймов и все чанки вне `npc_rename` — байт-в-байт** как
  в оригинале (сравнение на уровне чанков: `id`, `flag`, содержимое).
* **Единственное отличие — сжатие**: тот же текст упакован zlib-потоком на
  7 байт длиннее (сабчанк `13117` кадра `npc_rename`: 5974 против 5967 байт).
  Отсюда +7 к размеру файла: патч добавляет 112 байт, присланные файлы —
  119. После распаковки содержимое идентично.
* В exe нет ссылок на собственный размер, нет Authenticode-подписи, PE-заголовки
  и оверлей не тронуты; парсер игры ограничивает размеры чанков значениями
  `0x3333/0x6666/0x7f7f`, и 7 «лишних» байт сжатого потока ему безразличны.

## Что из этого следует

Файлы не могут быть причиной «даже не открывается»: так выглядит только exe
со сломанными PE-заголовками или обрезанным хвостом. Причину надо искать рядом
с файлом — и теперь это можно проверить на месте одной командой:

```
TE1_Mod_Launcher.bat --check-exe TheEscapists_eur.exe        # или .exe.txt-копию
TE1_Mod_Launcher.bat --verify                                # вся папка игры
TE1_Mod_Launcher.bat --revert-exe                            # вернуть оригиналы
TE1_Mod_Launcher.bat --status                                # размеры и sha1 + вердикт
```

Команды работают с лаунчером из корня репозитория (`TE1_Mod_Launcher.bat`,
сборка движка версии 1.2+). Подробности и чек-лист «если игра не стартует» —
в корневом `PATCH_NOTES.md`, п. 0 и 0.1.
