## 0. «Guard Key Names ломает exe»: как прислать мне 5 строк вместо 8 МБ

Запусти в папке игры из консоли (cmd):

```
TE1_Mod_Launcher.bat --status
```

и пришли то, что он напечатает. Выглядит это так:

```
game executables (the patch adds 112 bytes, nothing else):
  TheEscapists_eur.exe     patched        8000920 bytes  sha1 86f9d274e2aa...
    backup (pristine)      yes            8000808 bytes  sha1 cf7b416ca195...   [+112]
  TheEscapists_rus.exe     patched        8000945 bytes  sha1 5719956d044e...
    backup (pristine)      yes            8000833 bytes  sha1 d8e5dec339ec...   [+112]
  TheEscapists_pol.exe     patched        8000936 bytes  sha1 70581800f8e8...
    backup (pristine)      yes            8000824 bytes  sha1 fd8f022aba53...   [+112]
```

Что это значит: «backup (pristine)» — копия оригинального exe, которую лаунчер
кладёт в `mods\original\exe` перед патчем; `[+112]` — ровно столько байт
добавляет патч мода (структура PE при этом не меняется). Если у тебя числа
другие (например, `[+0]` или огромная разница) — файл правил кто-то другой
или он повреждён.

### Эталон из твоего же архива (part1/part2, `exe/game/*.exe.txt`)

Если у тебя та же сборка игры, эти контрольные суммы должны совпасть
байт-в-байт (патч детерминированный):

| exe | чисто, байт | sha1 чисто | после мода, байт | sha1 после мода |
|---|---|---|---|---|
| `TheEscapists_eur.exe` | 8000808 | `cf7b416ca19572edee37f3eb30f18d54e39fc279` | 8000920 | `86f9d274e2aa9786c318cc08fc70de4fe2b2d2d5` |
| `TheEscapists_rus.exe` | 8000833 | `d8e5dec339ec546977f69471402e7c169516c128` | 8000945 | `5719956d044e07215cbaeec40d7c9a82fe966bab` |
| `TheEscapists_pol.exe` | 8000824 | `fd8f022aba53f7c84256575a60cb5cfca7eee36c` | 8000936 | `70581800f8e8bd86712d187e93e9e3aae0d9dcd4` |

Проверить руками (PowerShell/cmd, из папки игры):

```
certutil -hashfile TheEscapists_eur.exe SHA1
```

**Если у патченого exe ровно «+112 байт» и sha1 совпадает — файл целый.**
Значит дело не в патче: проверь антивирус (не удалил ли файл в карантин),
запуск именно того exe (игровые — `TheEscapists_rus/eur/pol.exe`,
`TheEscapists.exe` — это фронтенд-лаунчер), и что установлен Python 3.

**Если запускать вообще нечего** — верни оригиналы: `--status` покажет,
есть ли бэкапы; «Guard Key Names» → Uninstall в меню лаунчера (или
Steam → «Проверить целостность файлов»).

## 1. Рандомизатор: перетасовка имён + прочность (`Decay`)

| Что | Как теперь |
|---|---|
| **Названия предметов** (`Name`) | **перетасовываются между предметами**: «Ключ от камеры» может стать «Чашка в виде оленя». Пул имён не меняется — ни одно название не теряется, ни один предмет не остаётся со своим прежним названием. Один seed → одинаковое соответствие во всех языковых файлах. |
| **Прочность** (`Decay`) | пересчитывается **у каждого предмета**. `Decay` — процент, который предмет тратит за одно использование: `5` = 20 использований, `0` = не изнашивается. Пул: `0, 1, 2, 2, 3, 5, 5, 8, 10, 10, 15, 20, 25`. |
| **Статы** | как раньше: `Weapon`, `Digging`, `Chipping`, `Cutting`, `Unscrewing`, `HP`, `FAT`, `Gift`, `Buy` + `Illegal` на «хаосе». |
| **Не трогается** | `Craft` (крафт в игре идёт по ID предметов), `Info`, `Found`, `Desk`, `Outfit`, `Carry` и прочие поля редактора тюрем. |
| `val.dat` | пересобирается автоматически под новые размеры файлов. |

## 2. Что нового для Guard Key Names (страховки)

1. **Запись exe проверяется чтением обратно**: если файл не выжил на диске
   (антивирус, квота, блокировка) — оригинал возвращается из бэкапа, в логе
   `read-back check failed … the original exe was put back`.
2. **Повреждённый exe лечится сам**: при следующем запуске лаунчер видит
   нечитаемый файл, кладёт на его место чистый из `mods\original\exe` и
   **заново ставит мод** («was damaged — the pristine backup was put back»).
3. **Отказ патчить при запущенной игре** (`the game is still running — close
   it and try again`), вместо непонятной ошибки блокировки Windows.
4. **`--status` печатает размер и sha1** каждого exe и бэкапа (см. выше),
   а сам `.bat` теперь пробрасывает ключи командной строки в движок.

Что проверено на реальных exe: патченый файл разбирается целиком (все 12
фреймов, каждая группа до последнего байта: `npc_rename` 55832/55832,
`game` 2420852/2420852, `tutorial` 760062/760062), движок и одиночный патчер
дают байт-в-байт одинаковый файл, в exe нет ссылок на собственный размер и
нет Authenticode-подписи, e2e-тест — ALL GOOD (установка, идемпотентность,
лечение после Steam «проверить целостность», откат, откат при порче записи,
лечение повреждённого файла).

```bash

python3 tools/test_launcher.py            # 53 проверки: перевод, рандомайзер, слежение за игрой
python3 tools/test_guardkeys_launcher.py  # e2e exe-мода (нужны образцы exe)
```
