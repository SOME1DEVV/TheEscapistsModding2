# Обновление лаунчера модов (The Escapists 1)

Готовый файл — **`TE1_Mod_Launcher.bat`** в корне репозитория (положить рядом с
`TheEscapists.exe` и запустить). Полный проект — в обновлённом
`TE1ModdingPart3.zip`.

---

## 1. Рандомизатор: перетасовка имён + прочность (`Decay`)

| Что | Как теперь |
|---|---|
| **Названия предметов** (`Name`) | **перетасовываются между предметами**: «Красный ключ» может стать «Туалетная бумага». Пул имён не меняется — ни одно название не теряется, ни один предмет не остаётся со своим прежним названием. Один seed → одинаковое соответствие во всех языковых файлах (`items_rus.dat` и `items_eng.dat` называют один и тот же предмет одинаково). |
| **Прочность** (`Decay`) | пересчитывается **у каждого предмета**, а не «если повезёт». `Decay` — процент, который предмет тратит за одно использование: `5` = 20 использований, `0` = не изнашивается. Пул: `0, 1, 2, 2, 3, 5, 5, 8, 10, 10, 15, 20, 25`. |
| **Статы** | как раньше: `Weapon`, `Digging`, `Chipping`, `Cutting`, `Unscrewing`, `HP`, `FAT`, `Gift`, `Buy` + `Illegal` на «хаосе». |
| **Не трогается** | `Craft` (крафт в игре идёт по ID предметов, `Craft=` нужен только для текста журнала), `Info`, `Found`, `Desk`, `Outfit`, `Carry` и прочие поля редактора тюрем. |
| `val.dat` | пересобирается автоматически под новые размеры файлов — игра не пишет «missing or corrupted». |

Тасовка обновляется при каждом запуске игры из лаунчера («Randomizer» →
Install, запуск из меню лаунчера).

Изменённые файлы: `launcher_src/te1_engine.py` (`DECAY_POOL`, `shuffled_names()`,
`randomize_items_text()`, текст меню мода), `tools/test_launcher.py` (+10 проверок),
`README.md`, пересобран `TE1_Mod_Launcher.bat`.

## 2. «Guard Key Names ломает exe — они не открываются»: что выяснено

Проверено на **настоящих** exe из игры (`TheEscapists_eur/rus/pol.exe`):

* патч добавляет 5 действий `act88("GuardName_N", "<ключ>")` в группу #15 фрейма
  `npc_rename` перед переходом на кадр 5 — ровно то место, где игра сама
  работает с `GuardName_*`;
* **патченый exe разбирается целиком**: все 12 фреймов, каждая группа — до
  последнего байта (`npc_rename` 55832/55832, `game` 2420852/2420852,
  `tutorial` 760062/760062 и т.д.). Структурно целый файл, «хвостов» нет;
* патчер и встроенный в лаунчер движок дают **байт-в-байт одинаковый** файл;
  пересборка нетронутых фреймов — тоже байт-в-байт;
* в exe **нет** ссылок на собственный размер/имя/командную строку и нет
  сертификата Authenticode (Certificate dir пуст) — то есть самомодификации
  и проверки целостности exe у игры нет;
* e2e-тест `tools/test_guardkeys_launcher.py` — **ALL GOOD**: установка на все
  три игровых exe, фронтенд `TheEscapists.exe` корректно пропускается
  («skipped — frame 'npc_rename' not found»), повторная установка
  идемпотентна, патч лечится после Steam «проверить целостность», откат
  возвращает исходные файлы байт-в-байт.

**Вывод:** в коде лаунчера причину воспроизвести не удалось — похоже на
окружение (антивирус, заблокированный/занятый файл, частичная запись, запуск
не того exe). Поэтому добавлены две страховки:

1. **Чтение файла обратно после записи.** Если антивирус, диск или блокировка
   испортили запись, лаунчер вернёт оригинал из бэкапа и напишет
   `read-back check failed … the original exe was put back` — «мёртвого» exe
   на диске не остаётся (раньше этого не проверялось).
2. **Отказ патчить, пока запущена игра.** Windows держит exe заблокированным,
   теперь вместо непонятной ошибки: `the game is still running — close it and
   try again`.

Если exe всё равно не запускается:

1. `TE1_Mod_Launcher.bat` → Guard Key Names → Uninstall (вернёт оригинал) или
   Steam → «Проверить целостность файлов»;
2. пришлите, что именно происходит (не открывается совсем / мелькает окно /
   ошибка ОС), **какой** exe вы запускаете и что пишет само меню мода
   (`TE1_Mod_Launcher.bat --status` покажет состояние каждого exe).

## 3. Как пересобрать и проверить

```bash
python3 tools/build_launcher.py           # собрать .bat из launcher_src/
python3 tools/build_launcher.py --check   # .bat не отстал от движка
python3 tools/test_launcher.py            # 53 проверки: перевод, рандомайзер, слежение за игрой
python3 tools/test_guardkeys_launcher.py  # e2e exe-мода (нужны образцы exe)
```
